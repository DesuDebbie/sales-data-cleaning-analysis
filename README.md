# Sales Data Cleaning & Analysis

This project was developed as part of my Data Analyst training at CESAE Digital, through the PRO_MOV by Reskilling 4 Employment programme.

I used Microsoft Excel to clean and analyze sales data, identify inconsistencies, and explore sales performance.

### What I worked on
- Identified duplicate records and data inconsistencies.
- Checked pricing errors, discounts, and mismatched IDs.
- Analyzed sales by product, city, category, and sales channel.
- Created a dashboard to visualize the results.
- Developed recommendations based on the analysis.

### Tools
- Microsoft Excel
- Pivot Tables
- Data Cleaning & Visualization

This project helped me develop my data analysis skills and understand how data quality can impact business decisions.
